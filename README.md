# summer-cv-practice

夏休みの深層学習の学習記録リポジトリ。

## 全体の軸：データの構造に合わせてモデルの構造を設計する

深層学習のモデルは「万能な関数近似器」ではなく、**データが持つ構造（対称性・局所性・出力の形）を帰納バイアスとして組み込む**ことで効率よく学習できる。
3つの実装を通して、データの構造 → モデルの構造 という対応を手を動かして確かめる。

| # | フォルダ | データの構造 | モデルの設計 | データセット |
|---|---|---|---|---|
| 01 | `01_pointnet_modelnet40/` | 順序のない集合（点群） | MLP ＋ 対称関数（max pooling） | ModelNet40 |
| 02 | `02_unet_oxfordpet/` | 空間的な局所構造（画像） | 畳み込み ＋ エンコーダ・デコーダ ＋ スキップ接続 | Oxford-IIIT Pet |
| 03 | `03_detr_voc2007/` | 物体の集合を出力する問題 | Transformer ＋ 集合予測 | PASCAL VOC 2007 |

## 各実装の位置づけ

### 01 PointNet — 順序のない集合 → MLP ＋ 対称関数
- 点群は点の並び順に意味がない（置換不変）。点ごとに共有MLPをかけ、max poolingという対称関数で集約すれば並び順に依存しない。
- 基礎: MLP、誤差逆伝播、損失と最適化、帰納バイアス

### 02 U-Net — 空間的局所構造 → 畳み込み
- 画像は近傍の画素が強く関連する（局所性・並進等変性）。畳み込みで重みを共有し、エンコーダ・デコーダとスキップ接続で「何があるか」と「どこにあるか」を両立する。
- 基礎: 畳み込み、プーリング、受容野、エンコーダ・デコーダ、スキップ接続

### 03 DETR — 物体の集合を出力 → Transformer
- 物体検出の出力は個数が不定の「集合」。Attentionで画像全体の関係を扱い、固定数のクエリから集合を直接予測し、ハンガリアンマッチングで予測とGTを一対一対応させる。
- 基礎: Attention、集合予測、ハンガリアンマッチング、転移学習

## 学習の流れ
01（集合・MLP） → 02（局所性・畳み込み） → 03（集合出力・Attention）の順に、帰納バイアスの種類を変えながら進める。


各実装フォルダには `train.py / evaluate.py / model.py / README.md / report.md / colab.ipynb` を置く（詳細は `CLAUDE.md`）。

## 実行環境とデータ取得元
- 動作確認: `python train.py --quick`（CPUのみ・データの一部・1エポック）
- 本番学習: Google Colab（T4 GPU）で各 `colab.ipynb` を実行
- データセットの取得元は各フォルダの `README.md` に明記する（公式配布元が使えない場合は信頼できるミラーを使い、その旨を記載）。
- ネットワーク制限でデータや事前学習済み重みを取得できない場合は、ダミーデータで動作確認のみ行い、その旨を各 README に書く。
